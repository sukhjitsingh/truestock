The framing on every row: this cannot be deleted
No delete action exists anywhere. Not a button, not an admin backdoor. Arizona A.A.C. R19-1-501 needs two years of invoices produced on request, and the only way to be sure is to make the document un-removable at write time. If a bucket rule is ever configured to expire objects, it is set far beyond retention_until — or, better, no lifecycle rule at all, because a silent deleter is exactly what no code review will catch.

An invoice whose date is still unknown gets the longest retention, never the shortest. There is no "delete" anywhere in this screen — the word is absent on purpose.

State: search finds nothing
Empty result: "No invoices match 'baileys'. Try a vendor name, an invoice number, or a wider date range." The search is honest — no "did you mean" guesses, no partial-credit results that look like the thing you asked for.
State: a document that never got approved
Rejected stays visible: a rejected invoice (a duplicate upload, a wrong vendor) remains in the archive, marked rejected with its reason, and is still exported in an audit packet with the rest — the packet is the truth of what was submitted, not only of what was approved.
