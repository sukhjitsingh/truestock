The rule under every row

A plausible-but-wrong number is worse than an obviously broken one. This screen never shows a derived total as if it were printed. If the lines don't sum to the printed total, both numbers are shown and the mismatch is the badge — never a silently "fixed" figure. And a NULL pack size on a case line is never coerced to 12: it stays an exception until a human types it.
